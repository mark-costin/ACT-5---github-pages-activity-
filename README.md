# Personal Hobbies Hub (Activity 5)

A responsive static website deployed via GitHub Pages that showcases my core hobbies: basketball, drawing, watching series and movies, and casual coding.

---

## 📋 Website Plan

* **Website Title:** Court, Canvas & Screen: My Personal Hobbies
* **Purpose:** To highlight my everyday passions—staying active with basketball, expressing creativity through drawing, unwinding with series and films, and tinkering with simple code projects—while completing our web publishing activity.
* **Target Audience:** Classmates, instructors, friends, fellow basketball players, art hobbyists, and movie/series fans.
* **Main Content:**
  * **On the Court (Basketball):** Favorite players, memorable moments, and personal highlights or pickup game stories.
  * **The Sketchbook (Drawing):** A curated gallery of sketches, illustrations, and creative ideas.
  * **The Watchlist (Series & Movies):** Top film recommendations, favorite TV shows/anime, and brief reviews.
  * **Code Corner (Casual Coding):** Simple interactive web experiments, scripts, and notes on what I am learning.
